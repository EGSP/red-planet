# Тестовые определения

Подпапка для видов, заведённых ради проверки, а не ради игры: копии с изменённой одной
величиной, заготовки на пробу, варианты силуэта. Сборка содержимого обходит
`resources/buildings/` рекурсивно, поэтому файлы отсюда попадают в справочник наравне
с остальными и видны в панели песочницы (F2).

В строительные панели (`resources/buildbars/`) тестовые виды не заносятся: игрок их
строить не должен, а панель песочницы ставит их помимо стройки.

Сейчас здесь лежит увеличенная копия завода ботов — `bot_factory_6x6`. Изменён только
габарит: прочность, цена, мощность сборки, направления выезда и масштаб спрайта унаследованы
у штатного завода 4×4.
