# Тестовые определения

Подпапка для видов, заведённых ради проверки, а не ради игры: копии с изменённой одной
величиной, заготовки на пробу, варианты силуэта. Сборка содержимого обходит
`resources/buildings/` рекурсивно, поэтому файлы отсюда попадают в справочник наравне
с остальными и видны в панели песочницы (F2).

В строительные панели (`resources/buildbars/`) тестовые виды не заносятся: игрок их
строить не должен, а панель песочницы ставит их помимо стройки.

Сейчас здесь лежат две копии завода ботов — `bot_factory_4x4` и `bot_factory_6x6`.
Изменены только габарит и масштаб спрайта: прочность, цена, мощность сборки и направления
выезда унаследованы у подлинника.

Масштаб спрайта у копий равен единице, то есть видимый корпус совпадает с занятым местом.
У подлинника он равен 1.2 — корпус выступает за занятое место на пятую часть, и на крупной
постройке этот выступ читался бы как расхождение картинки с застроенной площадью.

Размеры выбраны по видимому корпусу подлинника, а он равен 2.4 клетки (1.2 от габарита
2×2): 6×6 — ровно два с половиной раза от него, 4×4 — ближайшее целое к полутора разам
(3.6 клетки).
