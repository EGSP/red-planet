## 1. Три уровня описания

Система состоит из трёх уровней, и декали составляют лишь верхний из них.

### Уровень первый — отбор материала поверхности

Планетный биом (`terrain/desert.json`) перечисляет подбиомы с условиями отбора:

```json
"biomes":[
  {"spec":"/pa/terrain/sand/sand.json",        "temperature":[-1.0,1,1], "elevation":[-1,0.25,1],  "water_distance":[null,20,1]},
  {"spec":"/pa/terrain/desert/desert.json",    "temperature":[-1,1,2],   "elevation":[0.2,null,0.2],"water_distance":[150,null,1]},
  {"spec":"/pa/terrain/mountain/mountain.json","temperature":[-1,1,1],   "elevation":[0.4,1,3],     "water_distance":[null,null,0]}
]
```

Каждая тройка читается как нижняя граница, верхняя граница и вес; `null` означает отсутствие границы. Для точки
поверхности вычисляются высота, температура (производная от широты) и расстояние до воды, подбиомы получают веса и
смешиваются.

Сам подбиом (`desert/desert.json`) задаёт лишь общий цвет и одну повторяющуюся текстуру:

```json
{"name":"desert","color":[0.79,0.69,0.56,1],
 "base_texture":"/pa/terrain/desert/textures/base/desert_tile_diffuse.papa",
 "normal_texture":"/pa/terrain/desert/textures/base/desert_tile_normal.papa", ...}
```

Уникального изображения планеты не существует. Базовый слой есть карта весов малого разрешения плюс несколько
тайлящихся материалов.

### Уровень второй — поля шума, общие для размещения

В подбиоме объявлены 24 слоя:

```json
"layers":[
  {"note":"0","disable":true},
  {"note":"1","noise":{"scale":40,"zoom":10,"type":"simplex"}},
  {"note":"2","noise":{"scale":2,"zoom":10,"type":"simplex"},"inherit_weight":true},
  {"note":"3","noise":{"scale":4,"zoom":15,"type":"simplex"}},
  {"note":"4","inherit_noise":true},
  ...
  {"note":"23","inherit_noise":true}
]
```

Слои с `inherit_noise` переиспользуют поле предыдущего объявленного слоя. Смысл двоякий: шум вычисляется единожды на
точку, а два десятка слоёв читают одно значение; при этом номер слоя задаёт порядок наложения при отрисовке, отчего
песок ложится под трещины, а трещины под камни.

### Уровень третий — правила размещения декалей

Правила лежат в том же файле подбиома, в массиве `decals`:

```json
{"layer":10, "bias":100, "noise_range":[0.2,0.6], "pos_range":[0.0,0.0],
 "elevation_range":[-1.0,1.0], "biome_distance_range":[50,null],
 "scale":[70,70,1], "scale_variation":0.3, "count":1,
 "material_spec":"/pa/terrain/desert/decals/desert_cracks_decal_01.json"}
```

Значения полей:

| Поле | Назначение |
| --- | --- |
| `layer` | номер слоя шума, по которому проверяется условие, и порядок наложения при отрисовке |
| `noise_range` | диапазон значения шума, при котором декаль допускается |
| `elevation_range` | диапазон высоты |
| `biome_distance_range` | диапазон расстояния до границы биома; отодвигает декали от стыков |
| `bias` | вес при отборе кандидатов, то есть плотность |
| `scale`, `scale_variation` | размер и относительное отклонение размера |
| `count` | сколько экземпляров ставится в отобранной точке |
| `pos_range` | разброс положения относительно точки-кандидата |
| `material_spec` | ссылка на описание декали |

Само описание декали содержит только тройку текстур:

```json
{"diffuse":"...desert_rock_decal_01_diffuse.papa",
 "normal":"...desert_rock_decal_01_normal.papa",
 "material":"/pa/terrain/generic/decal_null_material.papa"}
```

## 2. Наблюдение о числе образцов

Декалей на биом немного: восемь для пустыни, порядка сорока на всю игру (`terrain/decal_list.json`). Разнообразие
достигается не количеством текстур, а сочетанием четырёх приёмов: разные поля шума дают несовпадающие области
размещения, случайный поворот и разброс масштаба разрушают узнаваемость образца, наложение слоёв порождает
комбинации, а условия по высоте и расстоянию до границы связывают рисунок с рельефом.

Это существенно для планирования работы над содержимым: набор из восьми-десяти образцов на биом достаточен, и
усилия следует вкладывать в правила размещения, а не в число текстур.

## 3. Перенос в red-planet

Структура переносится почти дословно, с заменой признаков отбора.

**Признаки.** Высоты, температуры и воды в проекте нет. Их место занимают расстояние до центра карты, номер кольца
руды из [`WorldRingDefinition`](../../../scripts/world/WorldRingDefinition.cs) и собственное шумовое поле. Диапазонные
условия при этом сохраняются без изменений.

**Описания.** Ресурс биома в `resources/` хранит список базовых материалов с условиями отбора, список полей шума и
список правил размещения — то же разделение на три уровня. Это согласуется с тем, как в проекте уже описан прочий
контент.

**Детерминированность.** Размещение вычисляется из зерна сессии и не сохраняется: при воспроизведении сессии из
журнала событий список декалей восстанавливается из того же зерна. Требование то же, ради которого PA передаёт по
сети зерно планеты, а не её содержимое.

**Порядок наложения.** Номер слоя следует сохранить как единственный источник порядка отрисовки, поскольку иначе
порядок начнёт зависеть от очерёдности вычисления и перестанет быть воспроизводимым.

Способ отрисовки разобран в [`pa-terrain-virtual-texturing-mavor.md`](pa-terrain-virtual-texturing-mavor.md).
