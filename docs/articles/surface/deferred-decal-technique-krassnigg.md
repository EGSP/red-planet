## Оговорка о полноте документа

**Содержание главы здесь не изложено.** Файл по приведённой ссылке при обращении отдаёт код 530, а страница
библиографической базы содержит только выходные данные без аннотации. Излагать главу по памяти и выдавать
изложение за пересказ источника было бы неверно, поэтому документ ограничен ссылками.

Публикация приведена как исходное описание метода: обе разобранные в соседних документах записи —
[`deferred-decals-mtnphil.md`](deferred-decals-mtnphil.md) и
[`screen-space-deferred-decals-wronski.md`](screen-space-deferred-decals-wronski.md) — излагают развитие того же
подхода и практически покрывают его содержание. Ознакомление с главой имеет смысл лишь при необходимости уточнить
первоисточник; для задач red-planet, где принимающая поверхность плоская, метод в исходном виде неприменим по
причинам, изложенным в разделе 5 записи Вроньского.

Если файл станет доступен либо появится другая копия, документ следует заполнить.
