# Редактор контента

Вкладка главного экрана Godot **Контент** (рядом с 2D / 3D / Script). Плагин: `addons/content_editor/`.

## Для агентов: где что лежит

| Часть | Путь | Роль |
|-------|------|------|
| Плагин | `addons/content_editor/ContentEditorPlugin.cs` | вкладка главного экрана, подписка на FilesystemChanged |
| UI | `addons/content_editor/ContentEditorMain.cs` и соседние | каталог, вкладки, форма, поле, баланс |
| Примитивы UI | `addons/content_editor/primitives/` | строки свойств, контекстные вкладки, таблица и граф |
| Состояние | `scripts/data/editor/ContentEditorStore.cs` | тексты, черновики, provenance, внешние правки |
| Схема полей | `scripts/data/editor/ContentSchema.cs` | что показывает форма |
| Запись TOML | `scripts/data/editor/TomlPatchWriter.cs` | точечная правка без потери комментариев |
| Отрисовка зданий | `scripts/draw/BuildingVisual.cs` | общий код с Building._Draw |

Неочевидные ограничения Godot и решения, принятые после обнаруженных дефектов,
собраны в [`docs/content-editor-tips.md`](content-editor-tips.md).

Черновики открытых вкладок подставляются в сборку через `ContentCompiler.CompileWithOverrides`. Глобальный `Content.Catalog` обновляется только после успешного «Применить» или явного «Перечитать».

## Запуск

1. Сборка проекта в редакторе (Godot подхватывает C#).
2. Вкладка **Контент** на панели режимов.
3. Если вкладки нет: `Проект → Настройки проекта → Плагины` — включить «Редактор контента».

## Режим «Сущности»

- Слева — отдельные вкладки каталога: юниты, здания, оружие и рабочие инструменты. Запись имеет вид `файл.toml (Отображаемое имя)`.
- Кнопка **Открыть на весь экран** переносит редактор в отдельное полноэкранное окно. Кнопка **Вернуть в редактор** и закрытие отдельного окна возвращают его во вкладку **Контент**.
- Щелчок по записи открывает нативную вкладку Godot с крестиком внутри неё. Повторное открытие активирует существующую вкладку; несохранённые файлы помечаются `*`.
- По центру — общее измерительное поле: все открытые сущности с включённым «Показывать на поле» рисуются вместе. Активная выделена; объекты перетаскиваются. Кнопка **Раскладка** расставляет их автоматически.
- Справа — форма свойств по секциям TOML. Обычная строка имеет колонки «название»,
  «значение» и «источник/действия»; длинные значения переносятся под заголовок.
  У каждого поля указан источник значения:

| Метка | Смысл |
|-------|--------|
| в текущем файле | ключ записан в текущем файле |
| унаследовано | значение пришло из родительского определения |
| из файла переменных | ссылка на `*.vars.toml` или значение из него |
| по умолчанию | в файлах ключа нет, взято из кода |

- Изменение унаследованного поля автоматически создаёт локальное значение.
- Кнопка `↶` удаляет локальный ключ (и пустую секцию), после чего снова действует наследование.
- Кнопка `↗` открывает родительское определение в редакторе контента либо панель значений `*.vars.toml`.
- Для `*.vars.toml` кнопка `↗` открывает нижнюю контекстную вкладку со всеми значениями
  файла. Кнопка **Связи** открывает граф наследования, файлов переменных, оружия и рабочих
  инструментов. Контекстные вкладки закрываются крестиком. При выборе другого юнита граф
  обновляется, а вкладка vars сохраняется, если новый юнит ссылается на тот же файл.
- Связанные инструменты открываются отдельными вкладками из блока внизу формы.
- **Применить** пишет только локальные переопределения в `.toml`, сохраняя комментарии, затем пересобирает каталог. **Отменить** возвращает черновик к тексту с диска.

### Внешние правки файлов

Редактор сверяет метки времени `.toml` с диском:

- при возврате на вкладку **Контент**;
- при возврате фокуса в окно Godot;
- после сигналов `EditorFileSystem.FilesystemChanged` (с короткой паузой).

Если вкладка без локальных правок — текст подтягивается молча. Если есть несохранённый черновик — диалог: «Взять с диска» или «Оставить черновик».

### Измерительное поле

- Сетка: 1 клетка = 1 игровая единица = `Const.Unit` (64) пикселя.
- Линейки по краям, масштабная отметка «1 клетка».
- Переключатели: сетка, подписи размеров, footprint, зазор постановки, обзор, атака, работа.
- Колесо — масштаб, средняя кнопка — панорамирование, **Показать всё** / **1:1**, инструмент **Линейка** для расстояний между точками.

## Режим «Баланс»

Таблица по итоговым определениям: HP, цена, скорость, обзор, размер, DPS, дальность, HP/металл, время сборки при собственной мощности, чистые потоки энергии и металла, мощь армии и экспансии, мощность строительства. Двойной щелчок по строке открывает сущность во вкладках.

## Ограничения первой версии

Не входят: создание и удаление сущностей, редакторы buildbar / волн / тегов / `*.vars.toml`, пакетное редактирование строк таблицы, боевая симуляция.
